
# SmartRoad AI

## Intelligent Road Hazard Detection System

SmartRoad AI is a Computer Vision project designed
to detect road hazards and traffic objects using
Deep Learning.

## Objectives

- Detect potholes.
- Detect vehicles and pedestrians.
- Recognize traffic signs.
- Analyze images and videos.
- Provide real-time detection using a webcam.

## Technologies

- Python
- YOLO
- FastAPI
- React
- DVC
- MLflow
- ONNX
- Docker Compose
- GitHub Actions

## Project Structure

- data/: datasets
- notebooks/: experiments
- src/: machine learning code
- backend/: FastAPI application
- frontend/: React application
- models/: trained models

## Development

The model training will be performed using
Google Colab.
